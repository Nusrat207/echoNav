# # EchoNav

EchoNav is a mobile application built with Flutter, developed as part of a Software Development course. The app is designed to empower visually impaired individuals by offering accessible tools to assist with daily tasks, navigation, and communication. It utilizes voice control for hands-free interaction and AI-driven object recognition to offer real-time descriptions of surroundings. Additionally, it provides mobility assistance to enhance independence and includes features to help users manage tasks and stay socially connected.

## Getting Started

  flutter clean
  flutter pub get
  flutter run

## Features

- Voice-controlled navigation
- Object recognition and description
- Mobility assistance
